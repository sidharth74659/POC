**Rules:**

- Each slide must include a **title**.
- Slides should be separated using `---`.
- Use **Markdown syntax** throughout.
- Each slide should contain a **concise statement**, an **overview**, or a **list of items**.
- Apply appropriate Markdown elements such as:

  - Lists
  - **Bold**, _italic_ text
  - `Code blocks` where needed
  - **Bolded links**

- Follow a structured numbering format like: `1`, `1.1`, `1.2`, `2`, `2.1`, `2.2`, etc.

  - Each main point should have a **title or a question**.
  - Sub-points should provide the related **details or summary**.

- Keep each slide **concise and to the point**.
- Add a _subtle hint in italic text_ at the bottom of each slide(just text, no label) to help the presenter anticipate the next topic.
- Keep it light, conversational, and engaging.
- Do not make it complex, or too much text. Avoid redundancy.
- Split the content into multiple slides, if needed.
