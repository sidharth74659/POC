Frequently Asked Questions

How does the voice recognition work?

Our application uses the Web Speech API, which provides real-time speech recognition capabilities. The system processes your voice input and converts it to text, which is then sent to our AI-powered instruction processor.

What browsers are supported?

The application works best on modern browsers that support the Web Speech API, including Chrome, Firefox, Safari, and Edge. For the best experience, we recommend using the latest version of Chrome.

Can I use this application offline?

Currently, the application requires an internet connection for the AI instruction processing. However, the voice recognition and basic navigation features work offline.

Is my voice data stored?

No, we do not store your voice recordings. The speech recognition happens locally in your browser, and only the processed text is sent to our servers for instruction processing.
