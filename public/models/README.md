# 3D Models Directory

Place your rigged human model here as `RiggedHuman.glb`.

## How to Get a Model

Run one of these commands:

```
npm run get-model
```

This will show instructions for downloading a rigged human model.

## Model Requirements

For best results, your model should:

1. Be in GLB format
2. Be in T-pose or A-pose
3. Have a complete skeleton hierarchy including:
   - Spine, neck, head bones
   - Arm and hand bones including fingers
   - Leg and foot bones
4. Have blend shapes (morph targets) for facial expressions

## Recommended Sources

- [Mixamo](https://www.mixamo.com) - Free rigged characters
- [Sketchfab](https://sketchfab.com) - Free and paid 3D models
- [Blender](https://www.blender.org) - Create your own models
